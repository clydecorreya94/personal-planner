# 🌴 LifeDash | Personal Management & Planner

**LifeDash** is a privacy-first, serverless personal dashboard designed to act as a **single source of truth** for managing household chores, weekly purchases, and financial commitments.

Tailored specifically for Kerala households (including utilities like KSEB bills, KWA, Panchayat taxes, and local market runs), LifeDash runs entirely in your browser without requiring any backend server or database.

# 🚀 Running Locally

No backend server or build tools are required.

## Steps

1. Download or clone this repository
2. Open the project folder
3. Double-click the `index.html` file

The app will instantly run in your browser.

---

# 🌐 Deploy for Free using GitHub Pages

You can host LifeDash publicly for free using GitHub Pages.

## Deployment Steps

1. Upload the project files to a public GitHub repository
2. Open your repository
3. Navigate to:

   `Settings → Pages`

4. Under **Build and deployment**:
   - Select **Deploy from a branch**
   - Choose:
     - Branch: `main` (or `master`)
     - Folder: `/root`

5. Click **Save**

Within a few minutes, GitHub will generate a live public URL.
